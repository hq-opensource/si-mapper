## QUDT Ontology

The QUDT files can be downloaded from the GitHub server at https://github.com/qudt/qudt-public-repo.
Specific files can be cherry-picked as needed from https://www.qudt.org/catalog/qudt-catalog.html, or an entire Release can be downloaded as a zip file at https://github.com/qudt/qudt-public-repo/releases. For more information, see https://github.com/qudt/qudt-public-repo/wiki/Installing-QUDT-for-Consumers.
