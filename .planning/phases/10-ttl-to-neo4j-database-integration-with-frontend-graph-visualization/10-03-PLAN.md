```typescript
const DEFAULT_COLOR = "#64748b";  // Slate — unknown/other types

function getNodeColor(type: string): string {
  // Check exact match first, then check if any key is a substring of the type
  if (TYPE_COLORS[type]) return TYPE_COLORS[type];
  for (const [key, color] of Object.entries(TYPE_COLORS)) {
    if (type.includes(key)) return color;
  }
  return DEFAULT_COLOR;
}
```

**Component architecture:**

1. **`GraphWindow` (exported)** — top-level component:
   - State: `data: GraphData | null`, `loading: boolean`, `error: string | null`
   - Fetches `GET /api/graph` on mount
   - Shows `StatusPlaceholder` with `Network` icon for: loading ("LOADING GRAPH" / "Fetching nodes and relationships from Neo4j..."), error ("GRAPH UNAVAILABLE" / "Could not connect to the graph API. Ensure Neo4j is running."), empty ("NO GRAPH DATA" / "Run 'Load TTL to Neo4j' from the agent to import the current ontology")
   - When data has nodes, renders `<SigmaContainer>` with `<GraphLoader>` and `<GraphEvents>` as children
   - SigmaContainer settings from UI-SPEC:
     ```typescript
     settings={{
       renderEdgeLabels: true,
       defaultEdgeType: "arrow",
       labelFont: "Outfit, Inter, system-ui",
       labelSize: 12,
       labelWeight: "700",
       labelColor: { color: "#94a3b8" },
       edgeLabelFont: "Outfit, Inter, system-ui",
       edgeLabelSize: 10,
       edgeLabelWeight: "700",
       zoomToSizeRatioFunction: (x: number) => x,
       itemSizesReference: "positions",
     }}
     ```
   - SigmaContainer must have `style={{ height: "100%", width: "100%" }}` and `graph={MultiDirectedGraph}`
   - The entire GraphWindow wrapper div: `className="relative w-full h-full"` (no SharedPageContainer wrapping — full-screen canvas)

2. **`GraphLoader` (internal child of SigmaContainer)** — loads graph data:
   - Uses `useLoadGraph()` hook
   - Uses `useWorkerLayoutForceAtlas2()` with settings from UI-SPEC (gravity: 1, scalingRatio: 10, barnesHutOptimize: true, barnesHutTheta: 0.5, slowDown: 5, adjustSizes: true)
   - In `useEffect([nodes, edges])`:
     - Creates `new MultiDirectedGraph()`
     - For each node: `graph.addNode(n.id, { label: n.label, size: Math.max(4, Math.log(degree + 1) * 8), color: getNodeColor(n.type), x: Math.random() * 100, y: Math.random() * 100, nodeType: n.type, properties: n.properties })`
     - NOTE: Degree is not known at add time. First pass adds all nodes with size=6, second pass updates size based on `graph.degree(nodeKey)`: `graph.setNodeAttribute(nodeKey, "size", Math.max(4, Math.log(graph.degree(nodeKey) + 1) * 8))`
     - For each edge: `graph.addEdgeWithKey(e.id, e.source, e.target, { label: e.label, type: "arrow" })` — wrap in try/catch to skip edges referencing missing nodes
     - `loadGraph(graph)`
     - `start()` to begin ForceAtlas2
     - Auto-stop ForceAtlas2 after 5 seconds: `setTimeout(() => stop(), 5000)`
   - Returns `null` (no DOM — just hooks)
   - Exposes `isRunning`, `start`, `stop` to parent via a ref or via a separate toolbar child component

3. **`GraphEvents` (internal child of SigmaContainer)** — registers hover/click events:
   - Uses `useSigma()` and `useRegisterEvents()`
   - State: `hoveredNode: string | null`, `clickedNode: string | null`
   - Register events:
     ```typescript
     registerEvents({
       enterNode: ({ node }) => setHoveredNode(node),
       leaveNode: () => { if (!clickedNode) setHoveredNode(null); },
       clickNode: ({ node }) => setClickedNode(prev => prev === node ? null : node),
       clickStage: () => { setClickedNode(null); setHoveredNode(null); },
     });
     ```
   - **nodeReducer** and **edgeReducer** passed to SigmaContainer settings (or set via `sigma.setSetting`):
     - When a node is hovered or clicked: that node highlighted (size * 1.5), its neighbors at normal rendering, all other nodes dimmed (color: `rgba(100,116,139,0.4)`, size * 0.6)
     - Edges connected to hovered/clicked node: full opacity. Other edges: hidden or very dim (`rgba(100,116,139,0.15)`)
     - Use `sigma.getGraph().neighbors(activeNode)` to get neighbor set
   - On Escape key: clear clickedNode (add `useEffect` with `keydown` listener for "Escape")

4. **Toolbar overlay** (rendered inside GraphWindow, positioned absolute):
   - Position: `absolute top-4 left-4 z-20`
   - Container classes: `flex flex-col gap-2 p-2 rounded-xl border border-[var(--muted-foreground)]/20 bg-[var(--background)]/80 backdrop-blur-md shadow-[0_8px_30px_rgb(0,0,0,0.04)]`
   - 4 icon-only buttons:
     - **Zoom In**: icon `ZoomIn`, `aria-label="Zoom in"`, `title="Zoom In"`, onClick: `sigma.getCamera().animatedZoom()`
     - **Zoom Out**: icon `ZoomOut`, `aria-label="Zoom out"`, `title="Zoom Out"`, onClick: `sigma.getCamera().animatedUnzoom()`
     - **Reset Layout**: icon `RotateCcw`, `aria-label="Reset layout"`, `title="Reset Layout"`, onClick: `sigma.getCamera().animatedReset()`
     - **FA2 toggle**: icon `Play`/`Pause` (conditional), aria-label/title per UI-SPEC table. Active state when running: `text-[var(--accent)] bg-[var(--accent)]/15 border-[var(--accent)]/10 shadow-sm`
   - Each button classes: `px-3 py-2 rounded-lg text-sm font-bold transition-all duration-300 flex items-center gap-2 border border-transparent text-[var(--muted-foreground)] hover:text-[var(--foreground)] hover:bg-[var(--foreground)]/5`

5. **NodeInfoCard overlay** (rendered inside GraphWindow, positioned absolute):
   - Position: `absolute bottom-4 right-4 z-20 w-[280px]`
   - Visible when `hoveredNode` or `clickedNode` is set
   - Container classes: `p-4 rounded-xl border border-[var(--accent)]/20 bg-[var(--background)]/90 backdrop-blur-md shadow-[0_8px_30px_rgb(0,0,0,0.12)] animate-in fade-in slide-in-from-bottom-2 duration-200`
   - Content:
     - Header: node label in `text-sm font-bold text-[var(--foreground)] truncate` + RDF type badge in `text-[10px] font-bold uppercase tracking-[0.3em] text-[var(--accent)] opacity-80`
     - Separator: `border-t border-[var(--muted-foreground)]/10 my-3`
     - Property rows:
       - "URI" key + full uri value
       - "TYPE" key + node type
       - "CONNECTIONS" key + degree count (`sigma.getGraph().degree(nodeId)`)
     - Key label: `text-xs font-bold uppercase tracking-[0.2em] text-[var(--muted-foreground)] opacity-60`
     - Value: `text-sm font-normal text-[var(--foreground)]`
   - To get node data: `sigma.getGraph().getNodeAttributes(activeNode)` for label, nodeType, properties

**Drag support:**
- Sigma.js v3 supports drag natively via `@react-sigma/core` — the `useSigma` hook provides drag capabilities. Use `enableNodeDragging` setting on SigmaContainer if needed, or implement via `downNode` / `mousemove` / `mouseup` events following the Sigma.js drag example pattern.

**CSS note:** The `animate-in fade-in slide-in-from-bottom-2` classes may require tailwindcss-animate plugin. If not available, use a simpler approach: conditional `opacity-0`/`opacity-100` with `transition-opacity duration-200` and `translate-y-2`/`translate-y-0` with `transition-transform`.

**CRITICAL ANTI-PATTERNS TO AVOID:**
- Do NOT forget `import "@react-sigma/core/lib/style.css"` — without it, the canvas has height 0
- Do NOT forget `x` and `y` attributes on nodes — ForceAtlas2 throws without initial positions
- Do NOT create the graph or call loadGraph outside of a SigmaContainer child — hooks only work inside SigmaContainer
- Do NOT use `graph.neighbors(node).length` — use `graph.degree(node)` (O(1))
