**Pattern:** Mirror `CodeWindow.tsx` structure exactly. Does NOT wrap in `SharedPageContainer` — the Sigma canvas must be full-screen (same as View/Edit iframe tabs). Renders directly as a full-height/width canvas surface.

```
GraphWindow
├── Sigma canvas (full-screen, WebGL, SigmaContainer)
│   ├── Node layer (WebGL rendered)
│   └── Edge layer (WebGL rendered, directed arrows)
├── Toolbar overlay (top-left, `absolute` positioned, `z-20`)
│   ├── Zoom In button
│   ├── Zoom Out button
│   ├── Reset Layout button
│   └── FA2 Run/Pause toggle button
├── Node Info Card overlay (bottom-right, `absolute` positioned, `z-20`)
│   ├── Visible on hover
│   ├── Locked on click (until click-elsewhere)
│   └── Properties: label, type, URI, connected count
└── Empty state (when /api/graph returns 0 nodes)
    └── StatusPlaceholder (existing component, icon=Network, title="No graph data", subtitle="Run 'Load TTL to Neo4j' from the agent to populate the graph")
```

**Loading state:** While `GET /api/graph` is in-flight, show `StatusPlaceholder` with a spinner-style subtitle "Loading graph data..." — use existing `StatusPlaceholder` component.

**Error state:** If API fetch fails, show `StatusPlaceholder` with subtitle matching the error state copy below.

## Interaction Contract

### Hover

- Sigma `nodeReducer`: on hover, increase node size by 1.5x, set border color to `#4f46e5` (accent).
- Show NodeInfoCard overlay (bottom-right) with node properties.
- Sigma `edgeReducer`: dim all edges not connected to hovered node to `rgba(100,116,139,0.15)`.
- All non-adjacent nodes dim to `rgba(100,116,139,0.4)`.

### Click (Lock)

- Locks the NodeInfoCard visible until user clicks elsewhere or presses Escape.
- Highlights all edges connected to clicked node at full opacity.
- All other nodes and edges dim to `rgba(100,116,139,0.2)`.
- Clicked node receives persistent highlight border (accent color ring).

### Click-elsewhere / Escape

- Clears locked highlight state.
- NodeInfoCard fades out.
- All nodes and edges return to normal rendering.

### Drag

- Standard Sigma.js drag behavior: `@react-sigma/core` drag plugin enables click-and-hold to reposition nodes.
- Node position is NOT persisted — resets on ForceAtlas2 restart.

### Zoom-triggered label visibility

- Sigma `zoomShowLabels`: enabled.
- Node `size` = `Math.max(4, Math.log(degree + 1) * 8)` — minimum 4px, scales logarithmically with degree.
- Nodes with `size >= 16` (high-degree): labels visible from zoom level 0.5+.
- Nodes with `size >= 8` (medium-degree): labels visible from zoom level 0.8+.
- Nodes with `size < 8` (leaf nodes): labels only visible at zoom level 1.2+.
- Edge labels: visible on hover only, or at zoom level 1.5+.

### Tab activation

- `GraphWindow` calls `GET /api/graph` on mount AND when the graph tab becomes active (via `useEffect` on `activeTab === 'graph'`).
- ForceAtlas2 starts automatically on data load, stops after 5 seconds of simulation (prevent infinite jitter).
