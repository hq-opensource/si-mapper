<objective>
Implement the `neo4j_prefix` backend mode.

All HVAC systems continue to share the single Neo4j Community Edition
`"neo4j"` database, but each system's nodes are tagged with a
`_graph_ns` (graph namespace) property equal to the system's ID.  This
enables per-system isolation — wipe, query, and visualise — without ever
issuing `CREATE DATABASE`.

Changes are confined to:
1. A new `get_graph_namespace()` helper (agent).
2. Namespace-scoped wipe and post-import `_graph_ns` stamping in the import
   tool (agent).
3. A `graph_namespace` informational field returned by `get_graph_schema`
   (agent) so the LLM knows to add `_graph_ns` WHERE filters to its Cypher.
4. A `?ns=` query param and `_graph_ns` WHERE filter in the frontend API
   route (mapper).
5. Frontend state passes `graph_namespace` alongside `neo4j_db_name`
   so the API route knows which namespace to filter.
6. A new rule in `master_instruction.md` for the `neo4j_prefix` Cypher
   Query Protocol.
</objective>

    def get_graph_namespace(tool_context) -> str | None:
        """
        Returns the graph namespace (= system ID) used to tag nodes in
        neo4j_prefix mode.

        - neo4j_prefix mode: returns active_system.id (never empty string).
        - All other modes: returns None (namespacing not applicable).

        Raises ValueError if backend is neo4j_prefix but no system ID is
        available in the tool context.
        """
        backend = get_graph_backend()
        if backend != "neo4j_prefix":
            return None
        if tool_context is not None:
            active_system = tool_context.state.get("active_system") or {}
            sys_id = active_system.get("id", "").strip()
            if sys_id:
                return sys_id
        raise ValueError(
            "Graph namespace not found. "
            "Ensure 'id' is set on the active_system in the tool context "
            "when using GRAPH_BACKEND=neo4j_prefix."
        )
    ```

    # Wipe

        )

        # neo4j_single: wipe entire database
        driver.execute_query("MATCH (n) DETACH DELETE n", database_=db_name)

    # n10s config drop (shared; only touch when no other namespace exists)
    if not ns:
        try:
            driver.execute_query("CALL n10s.graphconfig.drop()", database_=db_name)
        except Exception:
            pass
        driver.execute_query(
            "DROP CONSTRAINT n10s_unique_uri IF EXISTS", database_=db_name
        )
    ```

    After the `n10s.rdf.import.inline()` call (Step 6 in the original tool),
    add a namespace-stamping step for prefix mode:

    ```python
    # Step 6b (prefix mode only): stamp newly-imported nodes with the namespace
    if ns:
        driver.execute_query(
            "MATCH (n) WHERE n._graph_ns IS NULL SET n._graph_ns = $ns",
            {"ns": ns}, database_=db_name,
        )
        logger.info("Stamped imported nodes with _graph_ns='%s'", ns)
    ```

    The n10s init and uniqueness constraint are only managed in `neo4j_single`
    mode (or on first-run of prefix mode when the constraint does not yet
    exist).  For prefix mode the constraint is created once globally and not
    dropped between imports:

    ```python
    # Step 5: init n10s (always; idempotent)
    if not ns:
        # neo4j_single: safe to reinit every time
        driver.execute_query(
            "CREATE CONSTRAINT n10s_unique_uri IF NOT EXISTS "
            "FOR (r:Resource) REQUIRE r.uri IS UNIQUE",
            database_=db_name,
        )
        driver.execute_query(
            "CALL n10s.graphconfig.init({handleVocabUris: 'IGNORE'})",
            database_=db_name,
        )
    else:
        # neo4j_prefix: ensure constraint + config exist; skip if already set
        try:
            driver.execute_query(
                "CREATE CONSTRAINT n10s_unique_uri IF NOT EXISTS "
                "FOR (r:Resource) REQUIRE r.uri IS UNIQUE",
                database_=db_name,
            )
            driver.execute_query(
                "CALL n10s.graphconfig.init({handleVocabUris: 'IGNORE'})",
                database_=db_name,
            )
        except Exception:
            pass  # already initialised
    ```

    Note: because multiple systems share the graph, n10s.rdf.import.inline()
    will merge URIs across systems (same URI = same node).  This is acceptable
    for ASHRAE 223P ontologies which do not share instance URIs across
    buildings, but is documented as a known limitation.

    ### neo4j_prefix Mode — Namespace Filtering Rule

    When `get_graph_schema` returns `"graph_backend": "neo4j_prefix"`, all
    systems share a single `"neo4j"` database.  Each system's nodes carry a
    `_graph_ns` property equal to the system ID returned in `"graph_namespace"`.

    **Mandatory rule:** Every Cypher `MATCH` clause you write **must** include
    a `_graph_ns` filter:

    ```cypher
    MATCH (n {_graph_ns: "<graph_namespace>"})
    -- or --
    MATCH (n) WHERE n._graph_ns = "<graph_namespace>"
    ```

    Failure to add this filter will return nodes from all systems, not just
    the active one.  Always call `get_graph_schema` first to confirm the
    current `graph_namespace` value before writing Cypher queries.
    ```
