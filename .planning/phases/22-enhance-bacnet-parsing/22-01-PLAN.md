2. `_parse_bacnet_address(raw: str, component_type: str) -> tuple[str | None, str]`:
   - If not raw or "." not in raw → return (None, "skip")
   - Split on first "." → device, obj
   - Regex match r"([A-Za-z]+)(\d+)" on obj → type_code, instance
   - If no match → (None, "skip")
   - type_code = type_code.upper()
   - If type_code in SKIP_TYPES → (None, "skip")
   - obj_type = BACNET_TYPE_MAP.get(type_code) — if None → (None, "skip")
   - uri = f"bacnet://{device}/{obj_type},{instance}/present-value"
   - ref_type = "sensor" if component_type in SENSOR_COMPONENT_TYPES else "property"
   - Return (uri, ref_type)

3. `enrich_bacnet_point(point: dict, component_type: str = "") -> dict`:
   - raw = point.get("address", "")
   - enriched = dict(point) — shallow copy, do NOT mutate input
   - enriched["code"] = raw
   - uri, ref_type = _parse_bacnet_address(raw, component_type)
   - enriched["address"] = uri
   - enriched["ref_type"] = ref_type
   - return enriched

4. `enrich_flat_bacnet_points(metadata: dict, component_type: str = "") -> dict`:
   - result = {}
   - For key, val in metadata.items():
     - If key.startswith("bacnet_") and isinstance(val, dict) and "address" in val and "code" not in val:
       result[key] = enrich_bacnet_point(val, component_type)
     - else: result[key] = val
   - return result

5. Update `explode_bacnet_points` signature to `explode_bacnet_points(metadata: dict, component_type: str = "") -> dict`:
   - After line `result[f"bacnet_{i}"] = {"address": address, **point}`, replace with:
     `raw_point = {"address": address, **point}`
     `result[f"bacnet_{i}"] = enrich_bacnet_point(raw_point, component_type)`
   - The default `component_type=""` preserves backward compat — existing callers pass no arg and get ref_type="property" (non-sensor default).
