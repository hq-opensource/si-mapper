```python
def edn_to_mutable(data: Any) -> Any:
    if isinstance(data, Mapping):
        return {k: edn_to_mutable(v) for k, v in data.items()}
    elif isinstance(data, (list, tuple)) and not isinstance(data, str):
        return [edn_to_mutable(i) for i in data]
    else:
        return data
```

EDN key structure (from duct_manager.py, pipe_manager.py, electric_manager.py, custom_manager.py):
- Duct lines: key = `(Keyword("duct"), name)`, value = `{Keyword("n1"): {Keyword("pos"): [x,y]}, Keyword("n2"): {Keyword("pos"): [x,y]}}`
- Pipe lines: key = `(Keyword("pipe"), name)`, value = `{Keyword("n1"): {Keyword("pos"): [x,y]}, Keyword("n2"): {Keyword("pos"): [x,y]}}`
- Equipment/sensors: key = `(Keyword("obj"), name)`, value = `{Keyword("symbol"): "duct.fan", Keyword("name"): name, Keyword("pos"): [x,y]}`
- Fan/damper rotation: `Keyword("rot")` (NOT `Keyword("rotation")`)
- Rotation only written if non-zero: `if rotation != 0: new_value[Keyword("rot")] = rotation`

Define two public functions:

**`edn_comps_to_internal_grid(comps_map: dict) -> dict`**
- Accepts the mutable comps dict (already converted via `edn_to_mutable`).
- Iterates over key-value pairs. Keys are tuples `(Keyword, name_str)`.
- For each key:
  - Extract `obj_type = key[0].name if isinstance(key[0], Keyword) else str(key[0])`
  - If `obj_type == "duct"`: create component dict with `type="duct"`, `name=key[1]`, `start=list(value[Keyword("n1")][Keyword("pos")])`, `end=list(value[Keyword("n2")][Keyword("pos")])`
  - If `obj_type == "pipe"`: same as duct but `type="pipe"`
  - If `obj_type == "obj"`: look up `value.get(Keyword("symbol"))`. Get symbol string (`sym.name if isinstance(sym, Keyword) else str(sym)`). Look up in `SYMBOL_TO_AGENT`. If not found, log warning `f"Unknown EDN symbol '{symbol_str}' for component '{key[1]}' — dropping"` and `continue`. Create component with `type=agent_type`, `name=key[1]`, `coord=list(value.get(Keyword("pos"), [0, 0]))`. If agent_type in ROTATION_TYPES: read `value.get(Keyword("rot"), 0)` (NOT `Keyword("rotation")`) and set `component["rotation"] = int(rot) if rot else 0`.
  - Skip keys that are not tuple/list of length 2.
- Returns `{"components": components}`.

**`internal_grid_to_edn_comps(internal_grid: dict) -> dict`**
- Accepts `internal_grid` dict with `"components"` list.
- Builds a new dict of EDN comps entries.
- For each component:
  - If `comp["type"] in LINE_TYPES`: key = `(Keyword(comp["type"]), comp["name"])`, value = `{Keyword("n1"): {Keyword("pos"): comp["start"]}, Keyword("n2"): {Keyword("pos"): comp["end"]}}`
  - If `comp["type"] in COORD_TYPES`: key = `(Keyword("obj"), comp["name"])`, value = `{Keyword("symbol"): AGENT_TO_SYMBOL[comp["type"]], Keyword("name"): comp["name"], Keyword("pos"): comp["coord"]}`. If `comp["type"] in ROTATION_TYPES` and `comp.get("rotation", 0) != 0`: add `Keyword("rot"): comp["rotation"]` to value.
  - Else: log warning and skip.
- Returns the comps dict (to be placed under `Keyword("comps")` in the full grid).
