# Codebase Structure

**Analysis Date:** 2026-02-09

## Directory Layout
```
si-mapper-agentic/
├── .agent/             # Agent instructions, skills, and workflows
├── agent/              # Core AI Agent logic (Python)
│   ├── drawing_architecture/     # Drawing analysis level-based loops
│   ├── master_architecture/      # Orchestration logic
│   ├── equipment_architecture_optimized/ # Specialized equipment detection
│   ├── utils/          # Shared utilities
│   └── tools/          # Agent tool definitions
├── mapper/             # Next.js Frontend application (TypeScript)
│   ├── src/            # Frontend source code
│   └── scripts/        # Frontend utility scripts
├── mcp_server/         # MCP Server implementation
├── tests/              # Integration and unit tests
├── .planning/          # Project planning and codebase mapping
├── docker-compose.yml  # Orchestration configuration
└── README.md           # Project overview and deployment guide
```

## Directory Purposes
- **.agent/**: Contains the system instructions, skills, and workflows that define how AI assistants should interact with this codebase.
- **agent/**: The heart of the system. Implements multi-level agent architectures for processing HVAC drawings.
- **mapper/**: Provides a visual interface or specialized mapping tools for the HVAC graph data.
- **mcp_server/**: Implements the Model Context Protocol to expose tools (like database access or graph operations) to the agents.
- **tests/**: Contains test suites to verify integration flows and tool functionality.

## Key File Locations
- **Entry Points:** 
  - `agent/main.py`: Main entry for the agent system.
  - `agent/main_master_architecture.py`: Alternative entry for master architecture.
  - `mcp_server/server/`: MCP server entry points.
  - `mapper/src/app/page.tsx`: Main page for the React frontend.
- **Configuration:**
  - `agent/pyproject.toml`, `mcp_server/pyproject.toml`: Python dependencies.
  - `mapper/package.json`: Frontend dependencies.
  - `docker-compose.yml`: System-wide orchestration.
- **Core Logic:**
  - Distributed across `agent/drawing_architecture` and `agent/master_architecture`.

## Naming Conventions
- **Files:** Python files typically use snake_case (e.g., `level_4_act_loop.py`). Frontend files use PascalCase for components or kebab-case for others.
- **Directories:** Lowercase with underscores for Python, lowercase/kebab-case for others.

## Where to Add New Code
- **New Agent Logic:** Add to relevant architecture folder in `agent/`.
- **New Tool:** Add to `agent/tools/` or `mcp_server/`.
- **New Frontend Feature:** Add to `mapper/src/`.
- **New Integration Test:** Add to `tests/`.

## Special Directories
- **.planning/codebase/**: Stores the documentation generated by the codebase mapper.
- **.agent/**: Essential for maintaining consistent agent behavior across the project.
